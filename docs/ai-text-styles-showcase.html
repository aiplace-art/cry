Implementation Guide

  • CSS File: /public/variant-2/css/ai-text-styles.css
  • Usage: Add class to your "AI" text element (e.g., <div class="ai-text-frosted">AI</div>)
  • Button Size: Designed for 110x110px circular button with cosmic video background
  • Font Family: All variants use Inter font (system fallback included)
  • Animations: Chrome, Pearl, and Diamond variants include subtle animations
  • Accessibility: Respects prefers-reduced-motion and prefers-contrast
  • Mobile Responsive: Font size adjusts to 36px on screens < 768px
  • Recommended: FROSTED LUMINANCE (10/10), SILK CHROME (10/10), or PORCELAIN DEPTH (10/10)

Top Recommendations by Use Case

  • Maximum Elegance: FROSTED LUMINANCE or PORCELAIN DEPTH
  • Luxury Brand Feel: SILK CHROME or DIAMOND FACET
  • Minimalist Clean: PRISTINE CRYSTAL or GOSSAMER LIGHT
  • Unique/Memorable: PEARL ESSENCE or SOFT HALO
