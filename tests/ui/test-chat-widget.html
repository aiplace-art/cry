🛠️ Installation

Add the following code to your HTML to integrate Hyper Chat: 

<!-- Add before closing </body> tag -->
<script src="js/hyper-chat-widget.js"></script>

<!-- Auto-initialize with data attributes -->
<div data-hyper-chat-widget
     data-position="bottom-right"
     data-auto-open="false"
     data-show-notifications="true"></div>

Or initialize programmatically:

<script>
window.hyperChatWidget = new HyperChatWidget({
    position: 'bottom-right',  // bottom-right, bottom-left, top-right, top-left
    chatUrl: '/ai-chat-premium.html',
    autoOpen: false,
    showNotifications: true,
    playSound: false
});
</script>
