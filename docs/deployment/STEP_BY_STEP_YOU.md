### Шаг 5: Настроить Cron Job

**Действие:**
1. Найди вкладку **"Settings"** (слева в меню)
2. Прокрути вниз до раздела **"Cron"**
3. Нажми **"+ Add Cron Job"**
4. Заполни форму:
   - **Name:** `Twitter Auto-Poster`
   - **Schedule:** `0 8-22 * * *`
   - **Command:** `node scripts/twitter-scheduler.js`
5. Нажми **"Add"**

**Что это значит:**
- `0 8-22 * * *` = каждый час с 8 утра до 22 вечера (МСК)
- Система будет постить автоматически каждый час

**Результат:** Cron настроен

---

### Шаг 6: Проверить что работает

**Действие:**
1. Перейди во вкладку **"Deployments"** (слева)
2. Должен быть статус **"Success ✓"** зеленым
3. Перейди во вкладку **"Logs"** (слева)
4. Найди строчки типа:
   ```
   ✅ Twitter Auto-Poster initialized
   📅 Scheduled hours: 8-22
   ⏳ Waiting for next scheduled hour...
   ```

**Что делать если не видишь логов:**
- Нажми **"Redeploy"** в правом верхнем углу
- Подожди 1-2 минуты
- Обновить страницу логов

**Результат:** Система работает! Ждет следующего часа для поста
