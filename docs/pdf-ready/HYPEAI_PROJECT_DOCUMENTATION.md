# Appendix A: Glossary

**APY (Annual Percentage Yield):** Annualized return rate including compounding

**BEP-20:** Token standard on BNB Chain (Binance Smart Chain)

**Burn:** Permanent removal of tokens from circulation (sent to unrecoverable address)

**CEX (Centralized Exchange):** Binance, Coinbase, etc.

**DAO (Decentralized Autonomous Organization):** Community-governed entity

**DEX (Decentralized Exchange):** PancakeSwap, Uniswap, etc.

**DeFi (Decentralized Finance):** Financial services on blockchain

**KYC (Know Your Customer):** Identity verification process

**Liquidity Pool:** Token reserves for DEX trading

**Market Cap:** Total token supply × price

**Smart Contract:** Self-executing code on blockchain

**Staking:** Locking tokens to earn rewards

**TGE (Token Generation Event):** Token creation and initial distribution

**Utility Token:** Token used for platform services (not investment)

**Vesting:** Gradual token unlock schedule

**Whitelist:** Pre-approved list of investors
