## 🚀 Как Запустить

### Quick Start (5 минут)

1. Установить Redis:
   ```bash
   brew install redis
   brew services start redis
   ```

2. Установить зависимости:
   ```bash
   cd server
   npm install
   ```

3. Настроить .env:
   ```bash
   cp .env.example .env
   nano .env  # Добавить ANTHROPIC_API_KEY
   ```

4. Запустить сервер:
   ```bash
   npm run dev
   ```

5. Проверить:
   ```bash
   curl http://localhost:3001/api/ai-assistant/health
   ```

### Запустить Тесты

```bash
npm run test              # Run all tests (25 tests)
npm run test:coverage     # With coverage (80%+)
```
