## 📊 СТРУКТУРА СТРАТЕГИИ

### 30-дневный план разбит на 4 недели:

**Week 1 (Days 1-7): INTRODUCTION**
- Стиль: Минимализм и элегантность
- Цель: Brand awareness
- Типы: Logo reveals, простые infographics, quote cards

**Week 2 (Days 8-14): EDUCATION**
- Стиль: Инфографика и схемы
- Цель: Позиционирование как эксперты
- Типы: Performance charts, diagrams, agent spotlights

**Week 3 (Days 15-21): FEATURES**
- Стиль: Демонстрация и кейсы
- Цель: Showcase возможностей
- Типы: Service cards, metrics, before/after

**Week 4 (Days 22-30): LAUNCH**
- Стиль: Энергия и FOMO
- Цель: Максимальный hype
- Типы: Countdown timers, progress bars, celebration

## ⚠️ ВАЖНЫЕ ПРАВИЛА

### ✅ ВСЕГДА ДЕЛАЙ:
1. Используй **official logo** (`/website/logo-official-BRIGHT.svg`)
2. Используй **brand colors** (#00E5FF, #00AAFF, #0077FF)
3. Оптимизируй файлы (<5MB PNG, <15MB GIF)
4. Добавляй **alt text** для accessibility
5. A/B тестируй posting times
6. Отслеживай метрики daily
7. Отвечай на комментарии <30 минут

### ❌ НИКОГДА НЕ ДЕЛАЙ:
1. НЕ создавай новые логотипы (используй official!)
2. НЕ используй не-брендовые цвета
3. НЕ делай мелкий текст (<20px)
4. НЕ загружай неоптимизированные файлы
5. НЕ пости без alt text
6. НЕ игнорируй комментарии
7. НЕ меняй стратегию без данных
