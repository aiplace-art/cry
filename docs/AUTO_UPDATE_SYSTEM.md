## ⚙️ КАК ЭТО РАБОТАЕТ?

### 1️⃣ Git Hook (автоматически после коммита)
**Файл:** `/.git/hooks/post-commit`

**Что происходит:**
1. Делаешь `git commit`
2. Автоматически запускается hook
3. Hook запускает скрипт обновления
4. База знаний обновляется
5. Получаешь уведомление об обновлении

**Пример:**
```bash
$ git commit -m "Add new feature"

🔄 Обновление базы знаний проекта...

📊 Собрана информация:
   - Документов: 25
   - Контрактов: 8
   - Компонентов: 5 категорий
   - Новая версия: v1.2
   - Дата обновления: 2025-10-21

✅ База знаний успешно обновлена!
```

### 2️⃣ Скрипт обновления (вручную когда нужно)
**Файл:** `/scripts/update-knowledge-base.js`

**Запуск:**
```bash
node scripts/update-knowledge-base.js
```

**Что делает скрипт:**
1. ✅ Сканирует все документы в `/docs/`
2. ✅ Подсчитывает смарт-контракты в `/src/contracts/`
3. ✅ Подсчитывает компоненты в `/src/frontend/components/`
4. ✅ Обновляет версию (v1.0 → v1.1 → v1.2...)
5. ✅ Обновляет дату
6. ✅ Добавляет запись в историю изменений
7. ✅ Обновляет статистику проекта
8. ✅ Сохраняет изменения в файл

### 3️⃣ Агенты (автоматически после задачи)
**ПРАВИЛО ДЛЯ ВСЕХ АГЕНТОВ:**

После завершения задачи агент должен:
```javascript
// В конце работы
Bash("node scripts/update-knowledge-base.js")
```

**Это обеспечивает:**
- ✅ База знаний всегда актуальна
- ✅ Все окна видят свежую информацию
- ✅ Нет ручного обновления

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. Git Hook работает только при коммите
- ✅ При `git commit` - обновляется
- ❌ При добавлении файлов без коммита - НЕ обновляется
- 💡 Решение: Используй ручной запуск скрипта

### 2. Требуется Node.js
- Скрипт написан на Node.js
- Убедись что Node.js установлен
- Версия: Node.js 14+

### 3. Скрипт читает файловую систему
- Сканирует только определённые папки:
  - `/docs/`
  - `/src/contracts/`
  - `/src/frontend/components/`
- Если добавишь новые папки - обнови скрипт
