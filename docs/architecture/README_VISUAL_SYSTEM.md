## 💡 Key Concepts

### What This System Does

**Input:**
- Tweet category (e.g., "technical", "viral", "launch")
- Title text
- Optional: subtitle, service name, custom data

**Process:**
1. Select best template based on category
2. Load required assets (logos, fonts)
3. Render image using Canvas API
4. Optimize & cache
5. Return path to generated image

**Output:**
- Professional 1200x675px PNG image
- Optimized file size (<500KB)
- Branded with HypeAI visual identity
- Ready for Twitter upload

### Why Canvas?

**Chosen Technology:** Node.js Canvas (server-side)

**Reasons:**
- ✅ No browser required (pure Node.js)
- ✅ Fast rendering (50-300ms)
- ✅ Full control over design
- ✅ Low memory footprint
- ✅ Mature & stable library

**Alternatives Considered:**
- Puppeteer (slower, but handles complex CSS)
- Sharp (good for overlays, not full design)
- External APIs (costs money, rate limits)

### Template Selection

**Automatic Selection:**
```javascript
// Category determines template
'technical' → 'tech-gradient'
'viral' → 'meme-style'
'education' → 'minimalist'
'analytics' → 'data-viz'
```

**Manual Override:**
```javascript
// Force specific template
generate({
  category: 'technical',
  style: 'professional' // Override auto-selection
});
```

### Caching Strategy

**3-Level Cache:**
1. **L1 - Memory:** Hot images (50 images, 1 hour TTL)
2. **L2 - File System:** Generated images (7 days TTL)
3. **L3 - Template Cache:** Pre-rendered (30 days TTL)

**Performance:**
- First generation: 100-300ms
- Cache hit: <10ms (200x faster!)
- Expected hit rate: 80-90%

## 🔧 Technical Requirements

### Server Requirements

**Minimum:**
- Node.js 16+
- 2GB RAM
- 5GB disk space

**Recommended:**
- Node.js 18+
- 4GB RAM
- 20GB disk space (for cache)

**macOS Specific:**
```bash
# System dependencies for Canvas
brew install pkg-config cairo pango libpng jpeg giflib librsvg pixman
```

### Dependencies

```json
{
  "dependencies": {
    "canvas": "^3.2.0",      // Core rendering
    "sharp": "^0.33.0",       // Image optimization
    "twitter-api-v2": "^1.27.0"  // Already installed
  },
  "devDependencies": {
    "puppeteer": "^21.0.0"   // Optional: HTML rendering
  }
}
```

### Fonts Required

- **Inter** (Regular & Bold) - Modern sans-serif
- **Orbitron** (Bold) - Futuristic tech font
- **Impact** - Meme-style font (usually pre-installed)

Download links in Quick Start Guide.
